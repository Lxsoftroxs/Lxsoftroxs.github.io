Contribute to the Blog

Want to share your thoughts, poetry, stories, or ideas? You can contribute to this blog directly through GitHub!

How to Contribute

📝 Submit via GitHub Issue (Easiest)

The simplest way to submit your contribution - no technical knowledge required!

  1. Go to the GitHub Issues page
  2. Create a new issue with the title of your contribution
  3. In the description, paste your content (poetry, story, thoughts, etc.)
  4. Add a label for the type of content (poetry, blog post, etc.)
  5. Submit the issue and I'll review and add it to the site!

You'll need a free GitHub account to submit an issue.

🌐 Create a File Directly on GitHub

Add your contribution by creating a new file directly in the repository:

  1. Navigate to the appropriate folder:
    • _poetry for poetry
    • _posts for blog posts
  2. Click "Add file" → "Create new file"
  3. Name your file with the format: YYYY-MM-DD-title.md
  4. Add the required front matter at the top: 
    ---
layout: post
title: "Your Title Here"
date: YYYY-MM-DD
---

Your content here...
  5. Click "Propose new file"
  6. Submit the pull request and wait for approval!

💻 Submit via Pull Request (Advanced)

For those familiar with Git and GitHub:

  1. Fork the repository at Lxsoftroxs.github.io
  2. Clone your fork locally
  3. Add your content to the appropriate folder (_poetry, _posts, _journal, etc.)
  4. Commit your changes with a descriptive message
  5. Push to your fork and create a pull request
  6. Wait for review and approval

Submission Guidelines

  • Keep content respectful and appropriate
  • Original work only (or properly attributed)
  • No spam or promotional content
  • All submissions are subject to review before publishing
  • Please be patient - submissions will be reviewed as time permits

Need Help?

If you're having trouble submitting or have questions, feel free to open an issue and ask!
